DiPlay · Preface

DiPlay 星瑞 CarPlay

社区维护的 Android 车机项目，面向 Android 5.1 / E01。兼容性仍须按车辆、固件及手机组合验证。

下载安装包使用说明

下载与连接

当前版本 0.2.20.39，修复连接初期反复重连的问题。在 GitHub Release 附件中下载 APK。相同签名的 0.2.20.25–0.2.20.38 可覆盖升级；旧公开版 0.2.16.20 签名不同，需先卸载，设置会清除，请重新完成无线设置与授权。

USB 无需软件激活。未授权时点击首页“连接 CarPlay”直接进入申请页；首页“无线设置”可随时查看状态。已确认的有效授权支持离线连接。仪表地图视角同步及地图与仪表交替显示的问题仍未解决。

使用须知

本项目为社区非官方适配，与 Apple、吉利没有隶属或认证关系。请在安全停车时安装和操作蓝牙工具，提前确认备份及恢复方法。兼容性因车机、固件和手机而异，不保证未来系统兼容或服务持续可用。

Download and use

Download version 0.2.20.39 from GitHub Releases. It fixes repeated connection termination during startup. Same-signer local versions 0.2.20.25–0.2.20.38 can be updated in place. Public 0.2.16.20 must be uninstalled first because its signer differs; local settings are cleared. USB requires no software activation, and confirmed wireless approval supports offline startup. Instrument-map camera synchronization and map/gauge switching remain unresolved.

This is an unofficial community adaptation. Perform setup and maintenance only while parked, verify backups and recovery procedures, and read the disclaimer. Compatibility and continued service availability are not guaranteed.
