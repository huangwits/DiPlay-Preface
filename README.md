# DiPlay 星瑞 / Preface

面向吉利星瑞 E01（MT6735）车机的 CarPlay 适配版，支持 Android 5.1，界面为简体中文。

[下载安装包](https://github.com/huangwits/DiPlay-Preface/releases/latest) · [更新说明](https://github.com/huangwits/DiPlay-Preface/releases/tag/v0.2.16.14)

## 安装

当前版本 **0.2.16.14**。下载 Release 中的 APK，传到车机安装，并按提示授予所需权限。

已安装带更新功能的版本，可在“设置 → 关于 → 检查更新”下载新版。更新时直接覆盖安装，不要先卸载，以保留设置和授权信息。请在安全停车后完成安装与连接设置。

## 连接

- **USB**：连接 iPhone 后按界面提示操作，无需软件激活。
- **无线**：进入“连接 → 蓝牙工具”申请授权，通过后点击“连接 CarPlay”。已授权设备再次进入会自动联网核验，无需重复申请。

首次使用蓝牙工具，请按页面内的“完整操作说明”操作。“连接测试”仅用于兼容性检查，正式投屏使用“连接 CarPlay”。

## English

DiPlay Preface is a community CarPlay adaptation for Geely E01 / MT6735 head units running Android 5.1, with a Simplified Chinese interface. Current version: **0.2.16.14**.

Download the APK from [Releases](https://github.com/huangwits/DiPlay-Preface/releases/latest). If your version includes the updater, check Settings → About → Check for updates. Update without uninstalling to retain settings and activation information. Complete setup while safely parked.

USB requires no software activation. Wireless connections require approval and online revalidation. Follow the in-app Bluetooth setup guide; the compatibility test does not start CarPlay projection.

Compatibility depends on the vehicle, firmware and iPhone. This is an unofficial project with no Apple or Geely affiliation or certification. Read the [disclaimer](docs/DISCLAIMER.md) and [third-party notices](docs/THIRD_PARTY_NOTICES.md) before use.
