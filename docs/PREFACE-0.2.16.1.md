# DiPlay 星瑞 0.2.16.1

- 新增“设置 → 关于 → 检查更新”，可在车机上检查、下载星瑞新版并查看进度。
- 支持下载后覆盖安装；E01 可尝试原厂安装方式，也可选择系统安装。
- 下载失败可重试，已下载的安装包会保留；安装前核验版本、完整性和签名。
- 保留现有 USB 和无线功能。USB 无需软件激活，覆盖安装保留设置和授权信息。

适用于星瑞 E01 / MT6735、Android 5.1 起。请先结束 CarPlay 和蓝牙维护，在停车后安装。旧版没有更新入口，首次安装本版仍需使用原来的安装方法，之后可在应用内检查新版。原厂安装效果取决于车机固件，失败时可尝试系统安装。

本版参考上游的应用更新功能，未整体合入 0.2.16 的音视频及连接改动。

## English

- Added update checking and downloads from Settings → About, with progress shown on the head unit.
- Downloaded updates can replace the installed version. Compatible E01 units can try the factory installer, with system installation also available.
- Completed downloads are retained for retry. Version, integrity and signer checks run before installation.
- Existing USB and wireless behavior is preserved. USB needs no software activation; overlay updates retain settings and activation information.

For Geely E01 / MT6735, Android 5.1 or newer. End CarPlay and Bluetooth maintenance and park safely before installation. Install this first updater-enabled version using your existing method; check later releases in the app. Factory installation depends on firmware. This selectively adapts the updater, not all upstream 0.2.16 media and connection changes.
