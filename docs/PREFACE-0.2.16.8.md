# preface v0.2.16.8

- 首页、蓝牙工具、检查更新、连接准备、按键和投屏设置统一深色界面、按钮及文字样式。

## English

- Unified dark pages, buttons and text across connection, update, Bluetooth, steering and projection settings.
- Moved Bluetooth inspection results under the setup steps and shortened repeated instructions.
- Connection and update pages now stay dark independently of CarPlay day/night mode.

Install over the existing app to retain settings and authorization. Version `0.2.16.8` / `52`, Android 5.1 minimum. This is a local candidate; GitHub remains at 0.2.16.7. Boot hotspot behavior still needs vehicle confirmation.
