## English

- Bluetooth authorization now clearly states that activation is free and review is used to prevent abuse. The notice remains after approval.
- Manually upload a problem description and diagnostic report from Settings, then share the receipt with the maintainer for analysis.
- Cloud reports contain device diagnostics and recent app logs, are restricted to administrators and expire after seven days. Common secrets and addresses are filtered; avoid personal information in the description. Full local export remains available.

Retains the previous native map, Siri, wheel controls and installation flow. Full-map output and online installation still require vehicle verification.

Version `0.2.16.13` / `57`, Android 5.1 minimum. Local candidate; public release remains 0.2.16.7.
