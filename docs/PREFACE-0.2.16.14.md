# preface v0.2.16.14

- 缩小安装包：移除未使用的数据文件，无损压缩群二维码图片。
- 优化首次连接失败后的恢复：完成蓝牙适配后再次连接，会等待旧连接清理完成，并清除过期错误提示。
- 检查更新整合到“设置 → 关于”，确认安装后自动检查原厂安装权限。
- 更新三指飞屏与方向盘语音键支持；Siri 开关仅控制车机语音键唤醒。
- 增加手动上传诊断报告，便于反馈问题；蓝牙授权页明确显示授权免费。

适用于星瑞 E01 / Android 5.1。下载 APK 后直接覆盖安装，保留设置和授权信息。完整地图飞屏及原厂在线覆盖安装仍需实车验证。

## English

- Reduced APK size by removing unused data and losslessly compressing the group QR artwork.
- Improved recovery after a failed connection and Bluetooth setup: reconnection waits for the previous session to close and clears stale errors.
- Integrated updates into Settings → About, with factory installation permission checks after confirmation.
- Updated three-finger projection and steering-wheel voice support. The Siri switch controls the vehicle voice key only.
- Added manual diagnostic uploads and a clear notice that Bluetooth authorization is free.

For Geely E01 / Android 5.1. Install over the existing app to retain settings and activation. Full-map projection and factory online installation still require vehicle verification.
