# 使用说明

[返回项目首页](../README.md) · [文档目录](README.md)

本文面向当前公开版 **GeelyPlay 0.2.20.39**。车机型号、固件和 iPhone / iOS 版本会影响实际表现；首次使用前请阅读 [免责声明](DISCLAIMER.md)。

## 安装与升级

从本仓库的 [Releases](https://github.com/huangwits/DiPlay-Preface/releases) 下载 APK，并在安全停车后安装。

| 当前安装情况 | 升级说明 |
| --- | --- |
| 首次安装 | 下载 `GeelyPlay-v0.2.20.39.apk`，按车机提示安装 |
| 同签名的 0.2.20.25–0.2.20.38 本地版本 | 可直接覆盖升级，保留设置和有效授权 |
| 已安装 0.2.20.39 | 无需重复安装同一版本 |
| 旧公开版 0.2.16.20 | 因签名不同，先卸载旧版再安装；本地设置会清除，需要重新完成设置与授权 |

安装包面向 Android 5.1 / API 22 及以上的目标 E01 车机。系统版本满足要求不等于所有车型都已验证兼容。

GitHub Release 附件中的 APK 用于安装；自动生成的 **Source code** 压缩包用于查看源码。公开源码的构建限制见 [源码说明](../SOURCE_SCOPE.md)。

## USB 连接

1. 使用 USB 连接车机与 iPhone。
2. 按应用及系统提示完成连接。
3. USB 连接无需软件激活；如连接失败，记录提示内容后按本文“问题反馈”部分提供信息。

## 无线连接

1. 首次使用时，按应用内说明完成首页“无线设置”中的准备步骤。
2. 点击首页“连接 CarPlay”。未授权设备会进入申请页面。
3. 在“无线设置”查看申请状态、选择手机及使用蓝牙工具。

已确认的有效授权支持离线连接；连接后有网络时会在后台核验。待审、撤销或到期等状态，请按应用提示处理。授权与联网行为以实际安装版本为准。

蓝牙维护可能涉及车机系统组件。操作前应确认机型、备份状态和恢复方法，不要在行驶中安装、配对或修改设置。

## 已知限制

- 仪表地图可能与中控地图视角不同。
- 行驶中可能出现地图与仪表交替显示，当前公开版尚未解决。
- 连接、音频和车机控制需按具体硬件、固件及手机组合验证。

公开版的更新与已知问题以对应 [Release 说明](https://github.com/huangwits/DiPlay-Preface/releases/tag/v0.2.20.39) 为准。

## 问题反馈

先记录实际安装的应用版本，再按问题类型选择入口：

- [连接问题](https://github.com/huangwits/DiPlay-Preface/issues/new?template=connection.yml)：无法连接、卡在连接中、反复重连或断连。
- [其他故障](https://github.com/huangwits/DiPlay-Preface/issues/new?template=bug.yml)：安装、显示、音频或按键问题。
- [功能建议与一般问题](https://github.com/huangwits/DiPlay-Preface/issues/new?template=feature_request.yml)。

请提供车机型号与固件、应用版本、iPhone / iOS 版本、连接方式、复现步骤以及故障发生的大致时间。

如果可以进入应用，请在安全停车后复现问题，从应用的诊断页面保存、查看或分享报告。保留从开始连接到故障出现的相关记录；截图和视频可以补充现象。无法安装或无法打开应用时，提供系统错误提示，并说明无法导出报告的原因。

公开提交前请检查日志，移除个人信息、热点密码、配对记录和凭据。涉及安全缺陷或敏感数据时，先阅读 [安全说明](../SECURITY.md)。
