# 吉利星瑞兼容性 / Geely Preface compatibility

目标：Android 5.1 / API 22 及以上，ARMv7 与 ARM64。系统蓝牙默认启用；E01 ECARX 和 H52 ANW 需手动选择并依赖匹配车机服务。

不再提供 BYD / DiLink 专用功能。通用 Wi-Fi/USB、蓝牙、麦克风与音频仍依赖系统接口。桌面测试不等于实车验证。详见 [功能范围](GEELY-PREFACE-SCOPE.md) 和 [构建说明](BUILD.md)。

Target: Android 5.1 / API 22+, ARMv7 and ARM64. System Bluetooth is the default. Manual ECARX/ANW require matching vendor services. No BYD/DiLink vehicle integration is shipped. Real phone and vehicle validation remains necessary.
