# DiPlay 星瑞 0.2.16.3

## 更新内容

- 新增“设置 → 关于 → 检查更新”，可下载新版并覆盖安装；支持系统安装和适用 E01 的原厂安装方式。
- 蓝牙工具按安卓或原厂模式显示对应内容，可确认切换模式并重新选择手机。
- 连接等待页显示已保存的手机，采用居中的 CarPlay 图标与简短提示，适配横竖屏和矮屏。
- 改善部分旧安卓车机的授权证书兼容性，证书或日期异常时显示中文提示。
- 改善 USB 数据处理、VPN 授权异常提示、音频缓冲和麦克风编码；减少关闭未修改设置时的多余画面协商。

适用于星瑞 E01，Android 5.1 起。请停车并结束 CarPlay 与蓝牙维护后覆盖安装，不要先卸载，以保留设置和授权信息。已安装 0.2.16.1 或 0.2.16.2 的用户可直接在应用内检查更新；更早版本请下载下方 APK 安装。USB 无需软件激活，其他车型和固件仍需确认兼容性。

## English

- Added update checking and downloads in Settings → About, with system installation and a factory installer option for compatible E01 units.
- Bluetooth tools now follow the selected Android or factory mode. Switching modes requires confirmation and selecting the phone again.
- The connection screen shows the saved phone with a centered CarPlay icon and concise guidance, adapting to short and portrait displays.
- Improved license certificate compatibility on older Android systems, with clearer certificate and date error messages.
- Improved USB data handling, VPN authorization error handling, audio buffering and microphone encoding, and reduced unnecessary display negotiation when closing unchanged settings.

For Geely E01 running Android 5.1 or newer. Park and end CarPlay and Bluetooth maintenance before updating. Install over the existing app to retain settings and activation information. Versions 0.2.16.1 and 0.2.16.2 can check for this update in the app; earlier versions require installing the APK below. USB requires no software activation. Compatibility with other vehicles and firmware must be verified.
