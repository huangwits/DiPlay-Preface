# preface v0.2.16.9

- 检查更新、下载进度和安装按钮直接显示在当前设置或关于页面，不再打开独立更新页。
- 页面刷新或从系统安装界面返回时保留更新状态，已下载的安装包可以继续安装。
- 延续 0.2.16.8 的统一深色界面、蓝牙提示位置和开机热点改进。

车机联网后可检查和下载新版。E01 原厂安装依赖车机系统服务与安装权限，也可选择系统安装。覆盖安装保留设置和授权信息；原厂直接安装仍待实车确认。

版本 `0.2.16.9` / `53`，最低 Android 5.1。本版为本地候选，GitHub 公开版本仍为 0.2.16.7。

## English

- Check, download and install updates directly in the existing settings or about page.
- Keep update progress when the page refreshes or returns from the system installer, and retain downloaded packages for later installation.
- Includes the unified dark pages, Bluetooth status placement and boot hotspot improvements from 0.2.16.8.

Online checks and downloads require an internet connection. E01 factory installation depends on available system services and permissions; system installation remains available. Update in place to retain settings and authorization. Direct factory installation still needs vehicle confirmation.

Version `0.2.16.9` / `53`, Android 5.1 minimum. Local candidate; the public GitHub release remains 0.2.16.7.
