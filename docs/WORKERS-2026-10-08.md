# Workers 申请授权与源码交付（2026-10-08）

本轮按所有者确认完成可部署源码及本地验证。尚无公网地址，因此没有部署服务、没有生成可用线上完整 APK、没有推送 GitHub 或删除历史发布内容。

## 行为

`e01Licensed` 使用“车机请求 → 短申请号 → 管理员批准 → 页面自动取回许可”的流程。后台可批准、续期、停用；重复请求不会重置已停用状态。设备用本次安装的 AndroidKeyStore RSA 密钥签名挑战，D1 原子消费挑战；响应由 Workers Secrets 中的独立私钥签名，Android 验证设备、包名、安装签名和本次请求。连接许可最长 5 分钟、仅在进程内有效；已有 CarPlay 与蓝牙恢复不受影响。

个人 `e01` 免激活、不混淆；历史 `e01Public` 继续离线 r2 激活。两套既有密钥与安装签名未更改。新线上签发工具仅在部署者显式运行时生成独立线上密钥，私有目录必须位于源码外。

网站的旧安装包链接已替换为源码/构建入口。增加可用于恢复源码快照的扫描与源码打包器，拒绝身份、私钥、安装包、数据库、Secrets 和包含它们的嵌套 ZIP。全部公开输出均遵循 RELEASE-POLICY；历史无 Git 源码工作目录不能视为已推送提交。

## 验证

- 实际 workerd + 本地 D1：申请/批准/刷新/续期/停用、停用后重新申请、并发挑战重放、签名/设备/包名篡改、到期、管理认证、跨来源、请求大小、限流；含密钥生成/公私钥对应及拒绝覆盖，共 8 项测试通过。
- Android common/shared 合计 1,399 项：1,397 项通过，2 项需要完整实际 APK 的认证启动检查按设计跳过。本轮只构建不含身份的源码检查包，因此不声称已跑实际完整包认证。初次运行的新增跨端测试遇到 Android JSON 测试桩，改用既有 Robolectric 环境后单项复验成功。Worker 实际签名输出被 Kotlin 生产协议接受，篡改/换设备/重放被拒绝。
- 新增无激活码 UI 和协议检查，原有离线及连接回归保持通过。common/shared 与线上变体的 API 22 NewApi lint 通过；e01 / e01Public / e01Licensed 均构建成功，三个检查包没有身份或个人 GOC 二进制。两个授权变体均有实际 R8 类重命名。
- 14 项 Python 维护/分发检查通过；Workers 上传包 dry-run 通过，npm audit 为 0 漏洞。
- Playwright 浏览器验证 390×844 页面：登录、批准、停用、刷新清除登录，localStorage/sessionStorage 为空。临时浏览器及本地模拟服务已关闭。
